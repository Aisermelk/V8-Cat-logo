# Catálogo Virtual V8 — carrosséis de destaques e promoções

**ID do projeto V8:** `f3834657-9ddf-4798-a47e-2362fefd8814`

## Alteração
- Seção **Destaques** em carrossel horizontal.
- Seção **Promoções** em carrossel horizontal.
- Navegação com setas e arraste com mouse ou dedo.
- Layout responsivo para celular e desktop.
- Os destaques usam o campo `featured` dos produtos. As promoções usam `promotion`, `isPromotion` ou `onSale`, ou detectam preço original maior que o preço atual.

## Instalação
1. Publique `index.html` e a pasta `js/` juntos, mantendo `js/v8-loader.js` no caminho indicado.
2. No `index.html`, substitua `SEU_PROJECT_ID` no atributo `data-project-id` pelo ID real do projeto quando publicar. O ID de referência desta versão é `f3834657-9ddf-4798-a47e-2362fefd8814`.
3. Cadastre/publice os produtos no V8 Admin Universal e marque os itens em destaque ou promoção conforme os campos suportados pela sua configuração.
